# 標籤 horizon vs 持有期（2026-08-03）

> 使用者提問：「現在的模型是 **20 天再平衡**，但預測的是 **5 天後的排序**。
> 直覺上再平衡頻率應該低於預測天數才合理，是我誤解了什麼嗎？」
>
> **結論：直覺是對的，而且效應比預期大——但真正的機制不是『預測過期』，
> 是『短標籤的排序比較跳，追它要付過路費』。**

---

## 0. 先釐清三個「20d」

專案裡有三個容易混的軸：

| 軸 | 是什麼 | 目前最佳 |
|---|---|---|
| 看多長**歷史** | Scale Gate 的 Short/Mid/Long（20/60/252 步） | 單尺度（window 60） |
| 預測多遠**未來** | 5d / 10d / 20d 標籤 ← **本文件的主題** | 見下 |
| 多久**換一次股** | 再平衡頻率 | 20 日 |

`v2_kg_nomacro` 是「單尺度 · 預測 5d · 每 20 日換股」。

---

## 1. 實驗設計

**2 個模型家族 × 3 個標籤 horizon × 5 個再平衡頻率**，另加 Mamba 的雙頭對照。

| 項目 | 設定 |
|---|---|
| 模型 | Ridge（300 維）、GBDT（LightGBM）、Mamba（`ShortModelV6` 雙頭） |
| 標籤 | `rank_5d` / `rank_10d` / `rank_20d`（per-date pct-rank 置中 [−0.5, +0.5]） |
| 切分 | train 2013-01-01 → 2023-12-01（**purge 後**）、test 2024-01-02 → 2026-06-02（582 天） |
| purge | **三組一律 20 個交易日**（見 §1.1） |
| 組合層 | `portfolio_lab` v1.1，N=50 / k=1.5 / 無流動性過濾 |
| 其餘 | 旗標關、`fundamentals_v2` 開、`neutralize="none"`、成本 買 0.15% / 賣 0.45% |

### 1.1 為什麼必須先補 purge（否則實驗會偏袒 20d）

現行 `PROTOCOL` 是 `TRAIN_END=2023-12-31` **緊接** `TEST_START=2024-01-01`，
中間沒有間隔。在四階對照裡那是**共用**的缺陷（無害於相對比較），但——

**標籤 horizon 一變，缺陷的大小就跟著變**：5d 標籤洩漏 5 天、20d 洩漏 20 天。
不處理的話 20d 那組會白拿優勢，而它正是要檢定的對象。

→ 三組一律 `purge_days=20`（= 最長 horizon）。代價是每組少 20 個訓練日。
**連帶：本文件的 Ridge-5d ≠ 既有的 `ridge.parquet`**（那份沒 purge），
兩者不可混用；本文件自帶內部一致的 5d 基準。

### 1.2 跑之前定死的判讀規則

| 條件 | 結論 |
|---|---|
| `label=20d` 在 20 日再平衡下淨年化 ≥ `label=5d` **+2pp**，且 Ridge/GBDT 同向 | 對齊直覺有實質內容 → 值得上 Colab 訓 Mamba 的 20d 版 |
| 落在 ±2pp 內，或兩模型方向相反 | 標籤與持有期不必對齊，這條線收掉 |
| 明顯更差 | 反向結論（短標籤訊噪比更好） |

## 3. 機制：不是「預測過期」，是「短標籤的排序比較跳」

如果直覺的機制是「5 天後預測就失效了」，那長標籤應該只在**匹配的頻率**上贏。
實際不是——**Ridge 的 20d 標籤在五個頻率上全部最好**（連 1 日再平衡都是）。

真正的機制看換手就清楚了（20 日再平衡）：

| Ridge 標籤 | 換手 | 年化成本 | 毛報酬 | 淨年化 |
|---|---|---|---|---|
| 5d | 81% | 5.9% | 26.6% | +20.6% |
| 10d | 68% | 5.0% | 30.1% | +25.1% |
| 20d | **56%** | **4.1%** | **31.5%** | **+27.4%** |

**長標籤同時改善了兩端**：毛報酬更高（+4.9pp）**且**成本更低（−1.8pp）。
成本降低是因為**長標籤學到的排序本身更穩**——它獎勵的是「20 天內持續強勢」，
而不是「5 天內的短期彈跳」，於是名單的日間變動小、不需要一直追。

→ 使用者的直覺指到了真的東西，但要重新表述：
**問題不在「持有期超過預測期」，而在「短標籤製造了你付不起的換手」。**

## 4. 訊號層：對齊確實有效（對角線佔優）

同一份分數對三個評估 horizon 的逐日 Spearman IC（582 天）：

| 訓練標籤 | vs Alpha_5d | vs Alpha_10d | vs Alpha_20d |
|---|---|---|---|
| **Ridge** lab5d | **+0.0899** | +0.0851 | +0.0845 |
| Ridge lab10d | +0.0849 | **+0.0872** | +0.0919 |
| Ridge lab20d | +0.0790 | +0.0845 | **+0.0924** |
| **GBDT** lab5d | **+0.1010** | +0.0989 | +0.1000 |
| GBDT lab10d | +0.0892 | +0.0976 | +0.1033 |
| GBDT lab20d | +0.0863 | +0.0970 | **+0.1043** |
| **Mamba** `v2_kg_nomacro` 5d 頭 | **+0.1145** | +0.1183 | +0.1233 |
| Mamba `v2_kg_nomacro` 10d 頭 | +0.1115 | **+0.1216** | **+0.1311** |
| Mamba `v2_kg` 5d 頭 | **+0.0992** | +0.1041 | +0.1091 |
| Mamba `v2_kg` 10d 頭 | +0.0944 | +0.1049 | **+0.1121** |

**三個模型家族一致**：每個標籤在**自己的 horizon** 上（或更長的 horizon 上）表現最好，
換標籤到 5d 評估一律變差。這是教科書式的結果，但值得注意幅度不大（Ridge 只有 +0.0079）。

**一個有意思的不對稱**：所有模型對 `Alpha_20d` 的 IC 都比對 `Alpha_5d` 高，
連 5d 標籤訓練的也是（Ridge 例外）。→ 20 天的前瞻報酬本身比 5 天的**好預測**
（訊噪比較高），這獨立支持了 §3 的機制。

**`v2_kg_nomacro` 的 10d 頭對 Alpha_20d 是 +0.1311 / ICIR 1.490**，是本專案量過的最高值。

## 5. 大盤上升段 / 下跌段（N=50 / k=1.5 / 20 日）

分段依 `docs/portfolio-lab-results-2026-08-01.md` §7c 的定義：
**等權 eligible 宇宙過去 20 日累積報酬的正負**（不是前後半——§7c 已證明前後半兩側都是多頭）。
582 天中：**上升段 368 天 / 下跌段 195 天**。

| model | 全期 | 上升段 | 下跌段 |
|---|---|---|---|
| **v2_kg_nomacro** | +38.0% | **+91.9%** | **−24.2%** |
| gru | +31.3% | +73.9% | −19.9% |
| v2_kg | +26.0% | +58.2% | −15.8% |
| ridge | +21.2% | +48.5% | −15.1% |
| gbdt | +17.9% | +50.1% | −24.3% |

### ⚠️ 這一節修正了一個既有結論的適用範圍

§7c(⑩) 記過「`v2_kg` 的優勢來自**下跌段保護**，不是多頭助攻」。
**那對 `v2_kg` vs `no_gat` 成立，但對 `v2_kg_nomacro` vs `v2_kg` 不成立**——
`v2_kg_nomacro` 的優勢**全部在上升段**（+33.7pp），下跌段反而**更差 8.4pp**。

→ **+38% 對多頭 regime 的曝險比 `v2_kg` 更高**。這直接指向它最大的未解風險：
單一 582 天多頭窗、無 WF。移除 Group D 拿掉的是「記住是哪一天」的過擬合通道，
但看起來也拿掉了一部分下跌段的防禦性。

## 6. 限制

1. **單一 582 天多頭窗、單一 seed、無 WF** —— 與其他 Mamba 結果同一個限制。
   §5 顯示這個限制對 `v2_kg_nomacro` 特別要緊。
2. **Mamba 沒有真正的 20d 標籤組**。`ShortModelV6` 只有 `[head_5d, head_10d]`
   兩顆頭（`short_model.py:97-98`），20d 必須重訓。腳本已備好
   （`V6/experimental/head20d_ablation.py`，約 3.6h × 2 組），**尚未執行**。
3. **10d 頭不是「10d 標籤訓練的模型」**：它與 5d 頭共用 trunk，且 early stopping
   是看 5d 頭的 val IC 選的 checkpoint。所以 Mamba 那兩列比 Ridge/GBDT 的
   「一個模型一個標籤」弱一些，只能當方向性證據。
4. **purge 改動使本文件與既有四階對照表不可混用**（見 §1.1）。
5. 選擇偏誤：N=50/k=1.5 是既有分析選定的比較格，不是為本實驗重新挑的；
   但整份 300 格網格仍在，跨格挑最好的數字會帶偏誤。

## 7. 過程中查到的兩件事（都不影響結論，但要記下來）

### 7.1 `Alpha_Nd` 其實是原始前瞻報酬，沒有減大盤

`_add_alpha_targets` 用 `"TWII" in df_macro.columns` 決定要不要減基準，
而 `macro_raw` 的欄位叫 **`TWII_Close`**；把它改名成 `TWII` 的 `_merge_macro`
是在 `m = df_macro.copy()` 上做的 → **呼叫端的 `df_macro` 沒有 `TWII` 欄** → 走 else 分支。

實測：`Alpha_5d` vs `Fwd_5d` 的 **`max|Δ| = 0.000e+00`**（對照組差 0.183）。

**影響是零，不需要修**：標籤最後都轉成每日橫斷面 rank，而大盤前瞻報酬是**當日常數**，
減一個當日常數不改變當日排序；IC 是 Spearman，同樣免疫。
→ `label_10d.py` **刻意複製實際行為**（呼叫同一個函式、傳同一份 raw macro）。
把它「修好」反而會讓 10d 與既有 5d/20d 不同義，破壞整個比較。

### 7.2 base matrix 建好後，`prices_raw` 有一格歷史值被改寫

**2949 於 2026-07-29 的 Close 由 59.0 → 56.969006**（比值 0.9656 = 除息還原因子，
隱含股利約 2.03 元），連帶讓 `Alpha_20d @ 2026-06-29`、`Alpha_5d @ 2026-07-21` 兩列改變。

兩列都在 `TEST_END`（2026-06-02）**之後** → 對訓練與測試皆無影響。
`label_10d.py` 的閘門因此設計成「**協定窗內零容忍、窗外據實列出**」。
