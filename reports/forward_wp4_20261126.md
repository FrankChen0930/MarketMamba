## 持久化與恢復契約

- 固定 WP2 三 seed 17／29／43 及原 LightGBM 200 trees、185 features、n_jobs4 配方，不加 deterministic／force_col_wise、不調參或選 seed。合成矩陣800×185、獨立37列 probe；這不是 C0+ 真實矩陣重現或完整樣本訓練。
- 每一 fit **開始前**便把完整 environment 及 seed／context／params／target／environment SHA request 寫入獨立 `fit-attempt-*`，flush／fsync 檔案與 parent directories。若 fit 中斷，已落盤環境仍保留；未完成 attempt 不當模型版本。環境同時隨 seed model 再存於版本中。
- `publish_models` 先確認全部三 seed、明示 matrix／contract identity、fit matrix 與環境綁定；各 seed serialize→flush／fsync→size／SHA→manifest／directory fsync→沿用 Step3 resume 重驗。完整 local 三 seed manifest 封存後，複製到 `versions/.partial-*`，每檔 fsync、逐檔 durable reverify，且 durable manifest bytes 必須等於 local manifest。
- **切 pointer 前**，以 durable native model 載入，核 native seed／threads，再對 probe 預測；float64 shape／finite／全部 bytes 必須等於原預測。任何錯誤保留舊 pointer，不把 round-trip 檢查拖到切版之後。
- durable 版本 rename 為不可變 `version-UUID`、fsync versions；最後寫 fsynced `.pointer-*`、atomic replace `current.json`、fsync store。flock 保護現有 pointer 驗證與整體提交，三 seed 不會逐個切換；previous 只保存上一已提交 version／manifest hash，沒有 metric selection 或自動 best。
- load 只接受 current pointer 與 caller 的 exact context；重驗 top manifest、所有 files、各 seed request／環境／Step3 resume，再驗 native load/predict bytes。corrupt／missing pointer **STOP，不掃描最大日期、不自動 fallback、不提升 orphan**。存在 versions 卻無 pointer 時也拒絕重新訓練／建立新 pointer，須另案人工稽核；本輪未提供繞過 gate 的恢復捷徑。
- 跨 matrix 版本必須顯式傳入上一 context，先驗舊版，再原子發布新版；舊版 bytes 保持不變。不同 matrix／contract／seed 的 resume 拒絕。所有 symlink（含 pointer、manifest、model、目錄祖先）在讀內容或 hash 前拒絕。

這裡的 durable copy 是**同一 WSL 本機檔案系統中不同目錄的 fsync／copy／reverify**，不是不同硬碟備援、Windows／Drive／FUSE、斷電耐久或 hostile same-user 防竄改證明。partial／local／orphan 全部保留，未自動回收或升格。只有 current 是模型選用入口，沒有 performance-based best policy。

## 每 fit 的完整環境紀錄

包含 Python 版本／executable hash／compiler、platform／libc、完整 installed package name/version、LightGBM 版本、實際載入 shared libraries 與 NumPy extensions／interpreter 的 size／SHA、threadpoolctl 的 BLAS／OpenMP 資訊、NumPy build config、n_jobs4、OMP／BLAS／MKL 等 thread env、CPU count／affinity／完整 `/proc/cpuinfo` 與 flags、fit X 的 dtype／shape／strides／C/F layout／content identity。fit／predict 秒數亦存私有 telemetry。

同程序的大型 native binaries 依 realpath／device／inode／size／mtime_ns／ctime_ns 快取已驗 SHA；每 fit 重查 stat，變更則重新 hash，hash 過程發生變更即 STOP。每 fit 仍寫完整 binary map，並測同大小改寫會使 cache 失效。這是避免重複讀大量 runtime binaries 的本機工程選擇，不抵抗刻意同權限偽造。

這回應 WP2 缺原模型／完整編譯與 thread/layout 證據的診斷缺口，**不證實或修復 seed17 的既有未證根因，也不保證跨CPU／版本逐位元重訓**。本輪 round-trip 比較的是同次合成 fit 的保存／載入／預測，不以微小誤差或相同 ranks 放寬 bitwise gate。
