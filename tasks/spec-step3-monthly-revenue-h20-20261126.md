## 1. 一個問題、兩個模型

同一天、同一批股票，加入五個月營收欄位後，對未來二十個交易日價格變化的排序是否改善？A 為 185 欄 C0+，B 為相同 C0+ 加五個獨立數值欄，共 190 欄。兩臂都用 h20 重新擬合。唯一主對比為 B 減 A。季報保留 2b 描述，IFRS 單一匯出尚無首次版或重編版身分，故主家族 m=1。若日後認證季報，另案在新資料曝光前決定是否採兩個問題及 Holm m=2（為同時問兩題而調整錯判門檻）。h5、h60 僅容許描述，供應鏈、事件窗口與個別欄位不參與主判定。[研究計畫 §I–K](plan-fundamentals-supplychain-20261125.md)

已看過的月營收五欄等權 h20 平均 rank IC 為 2014–2020 的 0.0263、2021–2026 的 0.0152。後期對三種子 C0+(y5) 分數扣除線性關聯後為 0.0251。這三個數值只解釋為何提出問題。故意提前一個交易日使兩期 IC 升為 0.0306／0.0199，證明實際日期會影響結果；以次月十日替換發布日只造成小幅變化，兩者均無法驗證歷史值版本。[2b 描述報告](../reports/tej_diag_20261125.md)

## 2. 哪一天能用哪個數值

以台北日期 D 為來源記載的最早發布日，嚴格晚於 D 的首個合格交易 session **收盤**才可用，最早下個 session 開盤進場。前瞻另取「發布日規則」與實際收到並驗證完成的時間兩者較晚，錯過決策截點順延。缺日不補；週末連假按凍結日曆處理。每股以有效 session、原發布時間（僅日期者取日期）、營收年月、經驗證版本序、來源列識別穩定排序。同 session 先按原始先後套用全部事件，再取已知的最新營收年月算一次。晚到舊月份只能補當時起的歷史。相同邏輯鍵同版同值可去重留鏈，同鍵衝突且無原件可排序即 STOP；列號僅供一致重播。

令 R(m) 為該公司 m 月可驗的首次公告單月營收，單位統一為元。所有歷史項皆以訊號收盤當時已發布者為限。下表依序加到 B，維持原方向，無等權合成分數、事件年齡或額外缺值指標。

| 欄位 | 凍結定義 |
|---|---|
| 月營收年增率 | R(m) / R(m−12) − 1，對照去年同月。 |
| 月營收月增率 | R(m) / R(m−1) − 1，僅用相鄰月份。 |
| 年初至今累計年增率 | 分別加總本年一月至 m 月與去年一月至同月的首次單月值，再取兩組總和的比值減一。兩側月份均須完整，跨年度起點或口徑不明記缺。 |
| 十二月新高 | 本月嚴格高於前十二個完整月份的最大值為 1，持平或較低為 0，缺任一月為缺值。 |
| 營收意外程度（surprise） | 從 m 以前依營收年月倒序取最近三個可計年增率，中位數為 g。預期值 E＝R(m−12) × (1＋g)，欄值＝(R(m)−E) / abs(E)。三筆不足或 E 非正記缺。 |

比率分母須為正且各項有限。幣別、單位、合併範圍與跨期可比性須有同期證據；比較不成立記 NaN 及原因，不能將兩個 UNKNOWN 當相同。完整來源 gate 過關後，零星未公告或歷史不足的 NaN 由 LightGBM 原生處理，兩臂仍保留同一列。每折訓練與評估均須有五欄各自可觀測且具變異的支援，否則該折標 STOP，禁止彙總成完整研究。

2b 直接使用匯出的本年／去年累計，去年累計與上一年度原列有 20,169 筆不一致，非零分母 341,271 筆中有 7,028 筆差距超過 1%。原因可能是修訂或口徑，尚不能定論。改採逐月首次值重建，是為了把每個加數追溯到原公告；不並跑兩個版本擇優。2013/01 IFRS 轉換原始說明仍缺，本批合併欄全缺，逐月相加本身不能修復這兩項缺口。[2a 稽核](../reports/tej_pit_audit_20261125.md)／[2b 特徵實作](../tools/tej_diag.py)

## 4. 如何做同標籤、同支援的比較

**標籤與模型。** 訊號日為 t，持有第 1 日是 t＋1，第 20 日是 t＋20。兩臂共用 y＝close(t＋20) / open(t＋1) − 1。以 P1 的 `ace2eef` 配方為錨，基礎 48 欄、16 個核心欄位的 5 個落後值與 3 個移動平均、3 個市場欄各 3 個同日統計，共 185 欄。兩臂的 185 欄逐鍵相等，不加產業現況、不另行標準化。LightGBM 固定 200 棵、31 葉、學習率 0.05、葉節點至少 200 列、列抽樣 0.8 每輪一次、欄抽樣 0.8、L2＝10、四執行緒；種子 17、29、43。無內層搜尋、早停或選種子。「嵌套」指 B 包含 A 的全部欄位。[P1 規格](spec-portfolio-eval-20261119.md)／[C0+ 程式](../V6/research_lab/c0plus.py)／[種子分數與共同資格](../V6/research_lab/rolling_scores.py)

**期間。** 2013 僅有單月起始資料，2014–2020 整段已在 2b 曝光；建議用 2013–2014 累積同比、意外程度及可訓練歷史，2015–2020 六個年度外折報主要歷史量級。若直接以 2014 年初為首個預測點，2013 的訓練窗不足以學到完整同比訊號。2021–2026 六個年度折單列為後期已曝光對照，C0+ 設計亦受後期影響。2026 截至固定 2b 快照與矩陣共有的最後合格日，完整揭露預排與實際末日（2b 月營收等權末日為 2026-08-21，不能硬套到本案）。兩段均只作量級與工程驗證；歷史區間或顯著性無法建立確認性結論。

**切分。** 每年第一個 session 索引 o 為折界，以 2013 年起至 o 前逐年擴大的樣本訓練，基礎矩陣先前資料只供計算已知價量歷史。排除原 warmup，按完整候選訓練切分先驗 t < o−21，即最後訊號至多 o−22，並驗 t＋21 < o；這在出口 t＋20 後額外保守留白。僅收訓練截點前已取得且驗證的成熟 h20；核最大訓練出口及首個評估日，任何跨界 STOP。曆日不能替代交易日。評估保留尾端未成熟訊號，成熟後才取標籤；歷史封版後未成熟者維持缺值。[年度切分與安全邊界](../V6/research_lab/rolling_folds.py)

**共同列。** 每折固定原矩陣列序及日期／股票鍵。訓練取相同合格有限 h20，在每個完整訓練日截面算平均同秩百分位並減 (n＋1)/(2n)，再依同一種子無放回抽至多 500,000 列、排序索引。抽樣清單兩臂共用。沿用 P1 的 W60 資格於推論端，先封存全部應打分鍵，資格只看 t 以前及當日資料；不因 B 缺營收或未來缺標籤裁掉 A。六份原始分數逐折／日／股鍵必須完全一致、有限且無重複，標籤及 NaN 遮罩相同；少一種子或少一鍵即 STOP。每日從共同成熟列重算各臂三種子的截面百分位（同值取平均），種子等權平均後對共同 h20 求 Spearman，即股票預測名次與實際價差名次的相關。每日至少 20 股，常數截面或不足共同股數時兩側均記 NA。保留完整日期軸及缺值原因。[目標排名與抽樣](../V6/research_lab/matrix_baselines.py)／[2b 標籤與 IC 測例](../tests/test_tej_diag.py)

**判定。** 每日 d＝IC(B)−IC(A)，期間估計為合格日 d 的等權平均，不按股票數或種子數加權。每個期間獨立在完整 session 軸上做循環區塊重抽樣，連續 20 日為一塊，同抽兩臂，保留缺日位置；有放回抽至原長再截尾，1,000 次，seed 17。報百分位 95% 區間及平均差正負。20 日對應重疊持有期，更長的相依仍可能使區間偏窄。正式前瞻唯一成功規則為平均差 **至少 +0.005** 且雙側 95% 區間下界 > 0（單一主問題，無額外多重比較）。+0.005 是願意為五個額外欄位承擔資料維護成本的最低排序改善提案，沒有換算交易獲利，也不是由 2b 殘差倒推。下界 > 0 但低於實質門檻記「正向但不足」；其餘未過記「未證實」，不主張等效。歷史只列兩段各自的估計與區間，不投票、不合併成正式成功。
